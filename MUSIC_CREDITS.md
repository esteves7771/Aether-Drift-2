## Death cue

Playback uses **`death-cue.mp3`**, never the full `death.mp3`. The cue extracts **00:20.00–00:28.00** from the supplied death track, around an early dark-pulse entrance identified by RMS onset analysis. It is an eight-second stereo MP3 with an **80 ms fade-in** and **2.5 s fade-out**. Decoded length is exactly 8.0 s; the final 50 ms measures approximately -59.4 dBFS RMS.

Reproduce it with:

```sh
npm run music:cue -- --start 20 --duration 8
```

The editing helper uses FFmpeg with libmp3lame, accepts `FFMPEG_PATH`, and can reuse the ignored portable build in `.local-tools/`. `death-cue.edit.json` records interval, fades, codec, and source/output SHA-256 hashes. The original track remains unchanged. Runtime playback also enforces an eight-second cap and one-shot behavior.
